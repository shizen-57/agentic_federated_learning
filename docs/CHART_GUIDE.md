# Which chart goes on which slide

Seven charts in `figures/slides/`, generated by `scripts/slide_charts.py` from
the committed `results/*.csv` (regenerate with `python scripts/slide_charts.py`
after any new sweep). These are separate from `figures/*.png` at the repo
root, which are the per-round convergence line plots for the thesis document
itself -- these are the condensed, single-number-per-bar versions built for a
slide audience that will see each chart for ~20 seconds.

| # | File | Chart type | Slide it's for |
|---|---|---|---|
| 1 | `01_headline_accuracy.png` | Bar + error bars | **Opening results slide.** "Our system reaches the highest accuracy." One glance, one number per method. |
| 2 | `02_fairness_bar.png` | Bar + error bars | **Fairness slide.** Same method set, CV metric -- pair with #1 so the audience sees accuracy and fairness aren't traded off against each other. |
| 3 | `03_scorecard_grid.png` | 2x2 small multiples | **"Here's everything at once" slide.** Use when a reviewer/committee member might ask "what about cost/latency" right after #1 -- answer it before they ask. |
| 4 | `04_seed_variance_box.png` | Box plot + raw seed dots | **The rigor slide.** Answers "is this difference real or just noise?" before anyone asks -- shows the actual spread across the 5 seeds, not just a mean+-std bar. Use if presenting to a technical audience or during defense Q&A. |
| 5 | `05_tradeoff_scatter.png` | Scatter, emphasis form | **The "why does this matter" slide.** Proposed system highlighted top-left (cheap AND accurate), baselines grayed out as context. This is the single best one-image summary of the whole thesis if you only get one chart. |
| 6 | `06_ablation_bars.png` | Grouped bar, 3 panels | **The honesty slide** (Tasks 1-2 from docs/CONTRIBUTION_VALIDATION.md). Shows the ARL-vs-raw-failure-count ablation didn't show a big effect -- use this if asked "did you validate your own claims" or presenting the validation work itself. Optional: skip in a short talk, keep for a full defense. |
| 7 | `07_aggregator_bars.png` | Grouped bar, 3 panels | **The FedProx+FedNova combination slide.** Shows the 4-way aggregator comparison including the novel combined condition (c5). |

## Suggested slide order for a ~10-slide results section

1. Problem recap (not a chart)
2. `05_tradeoff_scatter.png` -- the one-image hook
3. `01_headline_accuracy.png` -- the headline number
4. `02_fairness_bar.png` -- the fairness claim
5. `03_scorecard_grid.png` -- pre-empt "what about cost/latency"
6. (convergence-over-time line plot from `figures/main_comparison.png` if you want to show *how* it gets there, not just the endpoint)
7. `07_aggregator_bars.png` -- the aggregation-rule finding
8. `04_seed_variance_box.png` -- rigor / Q&A defense
9. `06_ablation_bars.png` -- honesty about what the ablations did and didn't show
10. Limitations / future work (not a chart)

## Regenerating after a new sweep

```bash
python scripts/slide_charts.py --dir results --out figures/slides
```

It reads whatever `*_s<seed>.csv` files exist in `--dir` and groups them by
tag automatically -- no config needed. If a method referenced in the
`headline` list (`scripts/slide_charts.py`, `main()`) is missing from
`results/`, it's silently skipped rather than erroring, so partial sweeps
still produce whatever charts they can.

## Note on the diurnal-availability recalibration

These charts were generated from `results/*.csv` as committed at the time of
writing, which predates the diurnal-availability calibration in
`docs/REALISM_CALIBRATION.md`. If that sweep is re-run, regenerate these
charts from the fresh CSVs before using them in a defense -- the shapes of
the comparisons are expected to hold, but exact numbers will shift.
